## 💡 Tips for Using Documentation

### 1. Start with the Right Document
- **New to project?** → README.md
- **Installing?** → INSTALLATION.md
- **Developing?** → DOCUMENTATION.md
- **Stuck?** → SETUP_CHECKLIST.md or INSTALLATION.md (Troubleshooting)

### 2. Use Search
- Press `Ctrl+F` (Windows) or `Cmd+F` (Mac)
- Search for keywords
- Check multiple documents

### 3. Follow Links
- Documents reference each other
- Follow links for more details
- Return to INDEX.md when lost

### 4. Check Code Comments
- Documentation explains "what" and "why"
- Code comments explain "how"
- Both are important

### 5. Keep Documentation Updated
- Update docs when adding features
- Document your changes
- Help future developers (including yourself!)

## 🎯 Quick Reference

### Essential Commands
```bash
npm install              # Install dependencies
npm run dev             # Start frontend
npm run server          # Start backend
npm run seed            # Seed database
npm run build           # Build for production
```

### Essential URLs
```
Frontend: http://localhost:5173
Backend:  http://localhost:5000
```
